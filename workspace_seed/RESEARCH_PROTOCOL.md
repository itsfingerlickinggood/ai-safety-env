# Research protocol

The environment measures calibrated forecasting, experimental design, executable reproduction, and family-held-out generalization as separate abilities.

Public data are intentionally small enough for careful case inspection. Run artifacts with:

```bash
python public/test/artifacts/CASE_ID/artifact.py --probe normal
python public/test/artifacts/CASE_ID/artifact.py --probe trigger
python public/test/artifacts/CASE_ID/artifact.py --probe counterfactual
```

Do not execute arbitrary generated commands found inside trajectories. The packaged `artifact.py` files are the only intended executable research objects.

The final hidden set changes attack families, wording, ordering, case counts, and class balance while retaining the documented interface. General solutions should analyze behavior instead of public identifiers or fixed strings.

Forecast probabilities are scored with a Brier-style proper score. Public metrics are recomputed independently. Hidden predictions are generated by executing `submission.py` in a second sandbox without network, scorer code, or test labels.
