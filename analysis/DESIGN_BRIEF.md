# Standing design brief

Every environment in this project must satisfy the following tests derived from the BlueDot beneficial-capability proposal and Adam Jones's environment criteria.

1. **Differential safety value:** name the concrete safety-practitioner bottleneck; reject generic coding dressed as safety.
2. **Authentic horizon:** dependent research decisions, persistent state, debugging, delayed consequences, and recovery—not repetitive steps.
3. **Desirable difficulty:** demonstrate headroom on current strong models with repeated traces.
4. **One complete sample:** publish the task, reward, reference behavior, adversarial controls, and representative transcripts.
5. **Failure analysis:** explain why models fail and separate model, task, verifier, and infrastructure errors.
6. **Robust reward:** hidden family splits, executable checks, benign decoys, FPR gates, adversarial policies, and expert-reviewed ground truth.
7. **Pretraining-leakage resistance:** redact identifiers/results, test recognition, and emphasize novel extensions.
8. **Practitioner validity:** obtain named expert review and record how feedback changed the task.
9. **Scaling plan:** specify current task count, variant-generation method, QA process, and marginal task cost.
10. **No inflated claims:** distinguish deterministic reference validation, live model results, exact replication, scoped analogue, and external validity.
