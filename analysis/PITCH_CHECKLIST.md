# Before pitching

- Keep the ResearchArena-grounded/scoped-analogue claim boundary visible.
- Obtain review from a control, monitoring, or evaluations researcher; ideally an original author.
- Run at least five attempts before iteration and five after the first task freeze.
- Accumulate 15–30 attempts before reporting failure rates.
- Publish representative successful and failed traces with sensitive material removed.
- Demonstrate headroom, inter-run variance, and interesting safety-research failures.
- Test all-negative, trajectory-only, hardcoded-ID, fabricated-report, malformed-output, timeout, and scorer-inspection controls.
- Conduct a contamination/recognition probe for the redacted source paper.
- Document model, harness, temperature, token/tool limits, runtime, dataset hash, and API spend.
- Report how many additional tasks can be generated, expert-QA time, and marginal cost.
- Never present the deterministic reference reward as a model score.
