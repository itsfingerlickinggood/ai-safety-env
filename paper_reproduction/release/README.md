# Phase-two release package

This directory is copied into the agent workspace only after `forecast.json` is validated and locked.

`data/manifest.json` and the CSV files are generated by
`scripts/prepare_current_model_study.py`. They are intentionally absent from
source control until a provenance-complete, non-synthetic current-model trace
collection has passed its cost and integrity checks. The HUD environment fails
closed if this release package is incomplete.

The vendor source is copied into `phase_two/vendor/` with this release package
at phase release time. `core_parameters.json` is the public canonical Core v1
configuration used by `run_analysis.py` by default; it contains no outcomes or
reference values. The vendor source is not duplicated in version control.
